## Provenance

These packs were written from the WAKA STORY record: the three-page terminal
comics, the skill templates, and the mission artifacts and continuity log
from the author's own archive.

The character pack format follows the Runtime Familiars Package Format
Specification v1.0.0, whose reference implementation is the `moss` pack in
Resonant Constructs' specification repository. The reference implementation
was consulted for structure and house style; none of its prose, characters, or
settings appear here.

---

## Versioning

Each pack carries a version in `PACKAGE.json`. Minor versions add components,
expand dialogue, or add scenarios. Major versions change identity-defining
material and may not carry old conversations forward.
